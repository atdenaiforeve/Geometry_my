# INTO THE NEXUS

A horizontal, original Geometry Dash-inspired browser game built from scratch.

## 🎮 About

**INTO THE NEXUS** is a fast-paced geometric platform game where the player jumps, avoids obstacles, and travels through a futuristic Nexus.

The project is designed for both **mobile and computer/laptop** play, with touch and mouse/keyboard controls.

## ✨ Current Features

- Horizontal gameplay
- Mobile touch support
- Computer/laptop mouse and keyboard support
- Click-and-hold / touch-and-hold jumping
- Player rotation while airborne
- Blocks and spikes
- Level progression and level select
- Saved best progress
- Loading screen before the main menu
- Futuristic **THE NEXUS** visual style
- Creator Level Maker
- Large scrollable editor workspace
- Mobile editor scrolling and zooming
- Build, Edit, Delete, Move, Copy and Paste tools
- Object rotation
- Small precision tweaks for positioning and sizing
- Multiple block/object types
- Custom level names
- Test-your-level workflow
- Win Wall for controlling exactly where a level ends
- Creator levels can be published as official levels locally
- Performance-conscious rendering for larger levels

## 🛠️ Level Maker

The Level Maker is being designed as a proper large-world editor rather than limiting creators to the size of the phone screen.

Creators can:

- Scroll horizontally and vertically around the build area
- Zoom in and out
- Place objects at different heights
- Move and duplicate objects
- Rotate objects
- Make small precision adjustments
- Build long levels
- Place and resize a **WIN WALL** to control the finish
- Test a level before publishing it
- Give a level a custom name

The goal is to make level creation comfortable on both mobile and computer.

## 🏁 Levels

Creators can build their own levels and test them before publishing.
